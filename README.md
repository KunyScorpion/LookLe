## 📖 概要 (Overview)

**LookLe**（ルックル）は、大量のイラスト・コミック・自炊書籍・書庫ファイルを極めて高速かつ快適に閲覧するために設計された、Windows 向けのポータブル画像ビューアです。

往年の名作ビューアの操作性を踏襲しつつ、モダンな .NET 8 WPF、Direct3D HLSL による GPU ピクセルシェーダー、マルチスレッド先読みパイプラインを融合させることで、数万枚規模のライブラリや大容量書庫でもストレスのない軽快な閲覧体験を提供します。

## ✨ 主な特徴 (Features)

### 1. 📖 最適化された見開き表示 & 柔軟なページ送り
- **右開き (RTL) / 左開き (LTR) / 単ページ** のワンタッチ切り替え（`M` キー）。
- **見開き中央の隙間ゼロ密着表示**: 左右のページがシームレスに結合し、ワイドな見開きイラストも途切れず美しく描画。
- **表紙単独表示モード**: 1ページ目（表紙）を単独表示し、2ページ目以降を見開きにするインテリジェントなレイアウト（`C` キー）。
- **見開きずれ微調整**: `↑` / `↓` / `O` キーで瞬時に見開きペアを 1 ページシフト。

### 2. 🎨 Direct3D HLSL ピクセルシェーダーによるリアルタイム色調補正
- Direct3D 9 Pixel Shader 3.0（`ColorAdjustEffect`）による **CPU 負荷 0% の GPU リアルタイム補正**。
- **グレースケール（モノクロ化）ワンタッチトグル**（`G` キー）。
- **明るさ・コントラストの無段階微調整**（ツールバー 🎨 ボタンによる直感的なスライダー調整）。

### 3. 🔍 高度な拡大鏡（ルーペ） & スムーズズーム
- **2倍ルーペ機能**: `L` キーまたはマウスの中クリックで、カーソル周辺を高精細に拡大表示。
- **ルーペ形状切替**: `Shift + L` で「丸型ルーペ」と「角型ルーペ」を瞬時に切り替え。
- **マウスホイールズーム & 右ボタンドラッグパン**: 拡大中も滑らかに画面内を移動可能。

### 4. 🔄 画像中心軸回転 & 左右反転（ミラー）
- **個別画像回転**: `R` キーで画像の中心軸を維持したまま 90° / 180° / 270° 回転（回転時も画面内にジャスト収束）。
- **水平ミラー反転**: `H` キーで画像の左右を瞬時に反転表示。

### 5. 📦 書庫（ZIP / RAR / 7z / CBZ / CBR）の直接展開
- 書庫ファイルを解凍することなく、メモリ上でダイレクトにストリーミング展開・閲覧。
- 前後の書庫へのスキップ移動（`[` / `]` キー）。
- 二重書庫のフリーズ防止ガードなど堅牢なエラーハンドリング。

### 6. 🗂 本棚（お気に入り） ＆ エクスプローラー統合
- 左ペインにお気に入りフォルダを登録可能な「本棚」と「ファイルツリー」を搭載（`F4` キーで開閉）。
- ユーザーが変更したサイドバー幅（ドラッグ位置）を記憶し、最大化や全画面表示後も自動復帰。
- サムネイル一覧はホイール 1 行単位の高速スクロールに対応。

### 7. ⚡ ディスクサムネイルキャッシュ & パフォーマンス設計
- 高速なディスクキャッシュシステムにより、大量の画像フォルダでも 2 回目以降は一瞬でサムネイルを表示。
- 設定ダイアログからキャッシュ件数・容量の確認およびワンクリッククリアが可能。

## ⌨️ キーボードショートカット & 操作一覧

### 📖 ページ移動・見開き操作
| キー / 操作 | 動作 |
| :--- | :--- |
| `←` / `Space` / `PageDown` | 次のページへ進む（見開き時は 2 ページ送り） |
| `→` / `Shift + Space` / `PageUp` | 前のページへ戻る（見開き時は 2 ページ戻し） |
| `↑` (上矢印) | **【見開き補正】** 1 ページ戻す（見開きペアのずれを修正） |
| `↓` (下矢印) | **【見開き補正】** 1 ページ進める（見開きペアのずれを修正） |
| `Home` / `End` | 先頭ページ / 最終ページへジャンプ |
| `]` / `[` | 次のフォルダ・書庫 / 前のフォルダ・書庫へ移動 |
| `Backspace` / マウス `XButton1` (戻る) | 1 つ上の親階層フォルダへ移動 |
| マウスホイール | ページ送り（通常時） / スムーズスクロール（拡大時） |
| 画面左右クリック | 左半分クリック: 進む / 右半分クリック: 戻る |

### 🖼 表示・レイアウト・効果
| キー / 操作 | 動作 |
| :--- | :--- |
| `M` | 表示モード切替（単ページ ⇄ 見開き・右開き ⇄ 見開き・左開き） |
| `C` | 1 ページ目（表紙）の単独表示 ON / OFF |
| `O` / `Shift + C` | 見開き開始位置を 1 ページずらす |
| `1` / `2` / `3` / `4` | 表示フィット切替（全体表示 / 幅合わせ / 高さ合わせ / 原寸 1:1） |
| `G` | GPU グレースケール（モノクロ）表示 ON / OFF |
| `R` | 右へ 90° 回転（画像中心軸基準） |
| `H` | 左右反転（水平ミラー）切替 |
| `F4` | 左サイドバー（本棚 / エクスプローラー）の表示 / 非表示 |
| `F11` / `Enter` | 全画面表示 (フルスクリーン) 切替 |
| `Esc` | アプリケーション終了（設定ダイアログ表示時はダイアログを閉じる） |

### 🔍 ズーム・拡大鏡 (ルーペ)
| キー / 操作 | 動作 |
| :--- | :--- |
| `Ctrl + マウスホイール` | スムーズズームイン / ズームアウト |
| `+` / `-` | ズームイン / ズームアウト |
| `0` / `Ctrl + 0` | ズーム倍率をリセット (100%) |
| マウス中クリック / `L` | **【ルーペ】** 拡大鏡表示 ON / OFF（2倍拡大） |
| `Shift + L` | ルーペの形状切替（円形 ⇄ 矩形） |
| マウス右ボタンドラッグ | 拡大時の画像パン（スムーズ移動） |
| ドラッグ＆ドロップ (D&D) | フォルダまたは書庫ファイルをウィンドウに直接ドロップして開く |

## 📁 対応フォーマット (Supported Formats)

### 静止画像
- **JPEG** (`.jpg`, `.jpeg`)
- **PNG** (`.png`)
- **WebP** (`.webp`)
- **AVIF** (`.avif`)
- **BMP** (`.bmp`)
- **TIFF** (`.tif`, `.tiff`)
- **ICO** (`.ico`)

### 書庫ファイル
- **ZIP** / **CBZ** (`.zip`, `.cbz`)
- **RAR** / **CBR** (`.rar`, `.cbr`)
- **7-Zip** (`.7z`)

## 🛠 技術スタック & アーキテクチャ (Tech Stack)

- **ターゲットフレームワーク**: .NET 8.0 Windows (`net8.0-windows`)
- **UI フレームワーク**: Windows Presentation Foundation (WPF / XAML)
- **言語**: C# 12
- **GPU シェーダー**: Direct3D 9 HLSL Pixel Shader 3.0 (`ShaderEffect`)
- **書庫展開ライブラリ**: SharpCompress
- **単一ファイル配布 (Single-File Publish)**: 外部ランタイム不要の自己完結型 / 単一 EXE 出力に対応

## 🚀 ビルド & 実行方法 (Build & Run)

### 前提条件
- Windows 10 / 11 (64-bit)
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### 開発用ビルド & 実行
```powershell
# リポジトリのクローン
git clone https://github.com/KunyScorpion/LookLe.git
cd LookLe

# ビルド & 実行
dotnet run
```

### ポータブル単一実行ファイル (Single-File EXE) の発行
```powershell
dotnet publish -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true /p:IncludeNativeLibrariesForSelfExtract=true -o ./publish
```
※ `publish/LeeyesViewer.exe`（約 2.9 MB）として、単一の軽量ポータブル実行ファイルが生成されます。

# Leeyes Manga & Image Viewer - 開発引き継ぎサマリー (Handoff Summary)

本ドキュメントは、次回セッションで AI / 開発者が即座に開発を再開できるようにするための引き継ぎ用資料です。

---

## 1. 今回完了した実装・修正

- **画像中心軸での個別回転（90°/180°/270°）＆ 自動フィット**:
  - ビューア全体の回転から各画像要素（`ImgSingle`, `ImgLeft`, `ImgRight`）の個別 `LayoutTransform` による回転へ刷新。
  - 90°/270° 回転時、表示制約（`targetMaxW` / `targetMaxH`）を自動スワップして再計算し、画面外へはみ出さないよう完全収束。
- **左右反転（水平ミラー）機能（【H】キー）**:
  - キーボードの **`H`** キーおよびツールバーの **「⇄」ボタン** で単一画像・見開き左右両画像の水平ミラー反転をトグル切り替え可能に。
- **親階層へ戻るナビゲーション（【Backspace】＆ マウス【戻るボタン（XButton1）】）**:
  - フォルダまたは書庫の閲覧中、`Backspace` または 5ボタンマウスのサイド戻るボタンで即座に 1 つ上の親フォルダへ移動。
- **GPU シェーダーによる簡易カラー補正フィルター（モノクロ・明るさ・コントラスト）**:
  - Direct3D HLSL Pixel Shader 3.0（`ColorAdjustEffect.ps`）による CPU 負荷 0% のリアルタイム画像補正。
  - **`G`** キーでのワンタッチモノクロ化トグル、ツールバー **「🎨」ボタン** によるポップオーバー（明るさ・コントラストスライダー・リセット）。
  - XAML 解析時の `Slider.ValueChanged` 早期発火による起動クラッシュをガード節で解消。
- **見開き2ページ表示の隙間ゼロ化（シームレス密着）**:
  - 画像コンテナの左右マージン（`Margin="1,0"`）を `Margin="0"` に変更し、見開き時の幅計算をジャスト 50%（`viewportW / 2.0`）に最適化。
- **新ロゴアイコン（幾何学リーフ＆アイ）の適用**:
  - 32-bit ARGB 透過情報を維持したマルチ解像度 `app.ico`（256, 128, 64, 48, 32, 16）を生成し、EXE 本体およびウィンドウアイコンに設定。
- **左ペインのホイール1行分スクロール移動**:
  - 左ペイン（本棚・エクスプローラー）の `PreviewMouseWheel` を制御し、サムネイル 1 行分（**166px** / リスト時 **96px**）単位で高速スクロール＆境界クランプ。
- **ユーザーが変更した左ペイン幅の永続保持**:
  - 最大化・全画面（F11）解除時やサイドバー開閉時に初期値（290px）へリセットされず、ユーザーがドラッグした幅（`_lastUserSidebarWidth`）を復帰・保存。
- **実験的動画再生機能の検証と完全ロールバック**:
  - 実験実装前に Git タグ `v-before-video-experiment` を作成・保存。ユーザーのご指示に基づき、動画関連コードを残骸なく 100% クリーンに巻き戻し、静止画特化ビューアとして再パブリッシュ完了。

## 4. 採用した技術的決定・制約事項

- **静止画特化（軽量・高速優先）**:
  - アニメーション GIF/WebP や動画再生処理はオミットし、静止画（JPG/PNG/WebP/AVIF/BMP）および書庫（ZIP/RAR/7z/CBZ/CBR）の超高速展開に専念。
- **多重書庫のスキップ**:
  - 書庫内部を展開する際、内部に含まれる別の ZIP/RAR 等はフリーズ防止のため解析・展開をスキップ。
- **GPU アクセラレーションによる画像エフェクト**:
  - CPU 負荷ゼロで 4K/8K 画像の補正を行うため、WPF `ShaderEffect`（Direct3D HLSL PS 3.0）を採用。フィルター未使用時は `Effect = null` で完全パススルー描画。
- **回転・反転の座標系**:
  - ビューアコンテナ全体ではなく、各 `Image` コントロール自身の `LayoutTransform`（中心原点）で回転・反転を処理し、90°/270° 回転時は `MaxWidth`/`MaxHeight` の制約値をスワップして自動収束。
